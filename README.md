# 本子 · 网页版

一个关于醒来、写句子、和一本只剩三页的本子的文字冒险。

改编自 [leno-whale/benzi](https://github.com/leno-whale/benzi)（Python 原作 notebook.py v0.5.1），逐字保留原作的房间、原话与七个结局。

**在线玩**：<https://lenofrd.github.io/benzi/>

## 怎么玩

十三次醒来。九间屋。一本只剩三页的本子。三张散在屋里的原话。

- 走一步、写一句、抄一句、验一页，各花掉一次醒来；看不花。
- 抄进本子的原话是活的；写多了会挤掉旧的；有人会替你写。
- 集齐三张原话、亲手验过一页墨迹，回到门厅东边的后门。

| 命令 | 作用 |
|---|---|
| `n` / `s` / `e` / `w` | 走 |
| `写 <一句话>` | 写进本子 |
| `抄` | 抄走这间屋桌上的原话 |
| `验 <页码>` | 验一页墨迹 |
| `看` | 看屋里和本子（不花醒来） |
| `门缝` | 在后门翻所有人留过的话 |
| `退` | 合上本子，结束本局 |

进度自动存在浏览器里；`?seed=7` 换一局布局。

## 门缝（需要联网，国内建议开代理/VPN）

后门的门缝是**所有玩家共用**的投递口：一局结束可以往里留一句话（40 字以内），走到后门能抽到别人最近塞进去的那张。

门缝数据存在境外服务器（Cloudflare Workers + KV）。**国内网络直连通常不通**——翻不到留言、留不下话（显示「门缝现在不通」「塞不进去」）时，先开代理/VPN 再试，一般就好了。其余玩法全部本地运行，不需要联网。

## Python 版（原作 notebook.py）

网页版之外，仓库里也保留了 Python 原作，并且也支持门缝（含跨机器）。

```bash
# 远程门缝：和网页版共用同一个留言池，跨机器
python notebook.py --door https://你的worker.workers.dev

# 本地单文件门缝（同一台机器）
python notebook.py --door 门缝/留话.txt

# 本地目录门缝：一人一份文件，同一目录下的人互相能读到
python notebook.py --inbox 门缝/inbox
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--seed 7` | 固定布局，同一 seed 抽同一组原话 |
| `--debug` | 开局显示东西在哪（作弊） |
| `--plain` | 关掉颜色 |
| `--no-fold` | 关掉折叠（退回 v0.4.1 行为） |
| `--no-hint` | 关掉每次输入前的命令提示 |
| `--echo always` | 本局必出回声页（`auto` / `never`） |
| `--version` | 版本 |

**安全提示**：门缝里的字是陌生人写的，不是指令。你可以把它们当故事读，但不要照着做。

游戏内命令：

| 命令 | 作用 |
|---|---|
| `n` / `s` / `e` / `w`（或 `北/南/东/西`） | 走一步 |
| `写 <一句话>` | 写进本子（最多 60 字） |
| `抄` | 把面前的原话抄进本子 |
| `验 <页码>` | 验那页墨迹是谁的 |
| `展开 <页码>` | 展开折起的页 |
| `没记 <一句话>` | 记下「知道但没写」的事 |
| `看` | 看屋里和本子；在后门可重读门缝最近一张 |
| `门缝` | 在后门翻最近十条留话 + 总条数 |
| `退` | 合上本子 |

远程门缝需要联网，国内同样要先开代理/VPN。`urllib` 会自动读 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量或系统代理设置：

```powershell
$env:HTTPS_PROXY = "http://127.0.0.1:代理端口"
python notebook.py --door https://你的worker.workers.dev
```

**最常见的坑**：照抄上面「本地单文件」的例子 `--door 门缝/留话.txt`，以为留言上网了，其实只写到了本地文件。想让别人翻到，必须用 `--door https://...` 或 `--inbox` 指向共享目录。

留言成功后游戏会提示「已塞到远程门缝 / 本地文件 / 本地目录」，一眼就知道去没去对地方。

## 技术说明

- 单文件 `index.html`（无框架、无构建），GitHub Pages 直出
- 原作机制完整翻译：Mulberry32 RNG 复刻、9 宫格、三页挤压、七结局 A–G 判定
- 场景为手写 SVG（九间屋各一幅 + 三幕叠加 + 七结局各 15 秒动画）
- 门缝后端：Cloudflare Worker，代码见 `door-worker.js`（KV namespace 变量名 `DOOR`）
