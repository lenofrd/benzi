# 本子 · 网页版

一个关于醒来、写句子、和一本只剩三页的本子的文字冒险。

改编自 [leno-whale/benzi](https://github.com/leno-whale/benzi)（Python 原作 notebook.py v0.5.1），逐字保留原作的房间、原话与七个结局。

**在线玩**：<https://lenofrd.github.io/benzi/>

## 怎么玩

十三次醒来。九间屋。一本只剩三页的本子。三张散在屋里的原话。

- 走一步、写一句、抄一句、验一页，各花掉一次醒来；看不花。
- 抄进本子的原话是活的；写多了会挤掉旧的；有人会替你写。
- 集齐三张原话、亲手验过一页墨迹，回到门厅东边的后门。

| 命令 | 作用 |
|---|---|
| `n` / `s` / `e` / `w` | 走 |
| `写 <一句话>` | 写进本子 |
| `抄` | 抄走这间屋桌上的原话 |
| `验 <页码>` | 验一页墨迹 |
| `看` | 看屋里和本子（不花醒来） |
| `门缝` | 在后门翻所有人留过的话 |
| `退` | 合上本子，结束本局 |

进度自动存在浏览器里；`?seed=7` 换一局布局。

## 门缝（需要联网，国内建议开代理/VPN）

后门的门缝是**所有玩家共用**的投递口：一局结束可以往里留一句话（40 字以内），走到后门能抽到别人最近塞进去的那张。

门缝数据存在境外服务器（Cloudflare Workers + KV）。**国内网络直连通常不通**——翻不到留言、留不下话（显示「门缝现在不通」「塞不进去」）时，先开代理/VPN 再试，一般就好了。其余玩法全部本地运行，不需要联网。

## 技术说明

- 单文件 `index.html`（无框架、无构建），GitHub Pages 直出
- 原作机制完整翻译：Mulberry32 RNG 复刻、9 宫格、三页挤压、七结局 A–G 判定
- 场景为手写 SVG（九间屋各一幅 + 三幕叠加 + 七结局各 15 秒动画）
- 门缝后端：Cloudflare Worker，代码见 `door-worker.js`（KV namespace 变量名 `DOOR`）
